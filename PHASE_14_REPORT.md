## 5. Technical Engine & Publishing Automation

### 5.1 Publishing Engine (`scripts/build_blog.py`)
- **Strict Time Gate:** Renders only posts with `publish_date <= now_ist`. Future scheduled posts are strictly ignored during production rendering and their HTML files are automatically pruned if leftover from local testing.
- **Automatic Spec Table Injection:** Employs `{{spec_table}}` placeholder that pulls verified numerical parameters directly from `seo/product-master.json`, guaranteeing 100% concordance with product specifications.
- **Key Facts Table:** Employs `{{key_facts}}` placeholder rendering CAS, HS code, physical form, grade status, allowed packaging, and documentation.
- **Cross-Site Synchronization:** Updates the following secondary assets dynamically:
  - `blog.html` (SSR static grid + featured article + pagination controls).
  - `js/blog-data.js` (client-side data source for interactive category filtering and search).
  - `index.html` (homepage "Latest insights" section linking to the 3 newest published posts).
  - `sitemap.xml` (injects `<url>` blocks with `<lastmod>` matching post publication timestamp).
  - `blog/rss.xml` (RSS 2.0 valid XML feed with channel metadata).
  - `llms.txt` (structured index for AI search engines).
  - `seo/keywords.csv` (registers primary keywords to prevent cross-page keyword cannibalization).

### 5.2 Automation Script (`scripts/publish_automation.py`)
- **Vercel Deployment Verification:** Probes newly published URLs for HTTP 200 response with exponential backoff.
- **IndexNow & Sitemap Pinging:** Pings `api.indexnow.org` and Google Search Console sitemap ping endpoint upon deployment.
- **Automated Social Pack Generation:**
  - **LinkedIn Post:** Formats a 1,200–1,500 character technical article summary with 3 key technical takeaways, CTA link, and 3 approved hashtags (`#CastorOil #Oleochemicals #ChemicalManufacturing`).
  - **Instagram Carousel Script:** Formats a 5-slide technical script (Hook, Context & Origin, Specifications, Applications, CTA).
  - Creates a GitHub Issue titled `Social pack: <Post Title>` containing the copy ready for one-click manual sharing.
- **Queue Depth Monitoring:** Checks remaining future written posts (`written == 'Y'`). When the count falls below **8**, it automatically opens a GitHub Issue titled `Blog queue low – write next batch (weeks X–Y)` listing the next 26 calendar entries.

### 5.3 Automated Publishing Workflow (`scripts/workflows/blog-publish.yml`)
- Triggered weekly on Mondays at **01:30 UTC (07:00 IST)**.
- Executes `scripts/build_blog.py`. If a new post is rendered, commits changes to `main`, pushes to GitHub, triggers Vercel production build, and executes `scripts/publish_automation.py`.
